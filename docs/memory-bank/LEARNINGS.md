# Aprendizados reutilizaveis

- Regras obrigatorias pertencem ao `AGENTS.md`; memoria e uma camada auxiliar.
- O memory bank versionado deve conter fatos duraveis e nunca segredos ou dados importados.
- Um plano de mapeamento explicavel deve existir antes de qualquer gravacao.
- Correspondencia um-para-um evita que a mesma coluna alimente campos distintos silenciosamente.
